# 설치와 사용 방법

## 접속 주소와 사용 순서

**[대시보드 열기](https://safeguard.local:9443/dashboard)** · **[휴대폰 위치 전송](https://safeguard.local:8443/)** · [시작 화면·연결 코드](https://safeguard.local:9443/)

같은 네트워크의 SafeGuard Pi에 접속합니다. 서비스와 기기의 인증서 신뢰를 설정한 뒤 다음 순서로 사용합니다.

**Pi 전원 → 네트워크 연결 → 대시보드 로그인 → 휴대폰 위치 전송 시작 → 센서·온도·정지 상태 확인 → 감시 재개.**

웹 로그인과 휴대폰 연결 정보는 각각 7일 동안 유지됩니다. 최초 휴대폰 등록은 시작 화면의 8자리 코드를 사용하며, 만료·사이트 데이터 삭제·연결 초기화 시 다시 등록합니다. 휴대폰에서 위치 권한을 허용하고 '시연 시작'을 누른 뒤 화면을 켜 둡니다.

## 최초 설치·장치 연결

1. 전원을 끈 상태에서 하드웨어 계획에 맞게 ESP32·센서·출력 장치를 연결합니다. 실제 USB 경로와 서보 구동 범위를 확인합니다.
2. 제어 소스를 빌드하고 `real_navigation_control.json`의 장치 경로·펌웨어·센서 유효성 설정을 대상 장치와 대조합니다.
3. HTTPS 인증서·운영 비밀번호·위치 수신기와 서비스를 설정합니다. main/navigation/portal의 역할을 분리하고 중복 실행을 방지합니다.
4. 제어기를 정지 유지로 시작해 ESP32의 출력 OFF 보고를 확인합니다. 실제 대시보드와 제어 서비스 연결을 확인합니다.
5. 실내온도·위치/외기온·센서 상태를 확인하고 감시 재개 및 보호·전체 정지를 시험합니다. 선제 예측은 유효한 600초 이력과 모델 준비 상태를 확인합니다.
6. 정상 재부팅 후 자동 시작과 정지 유지·명시적 감시 재개를 확인합니다. 최초 설정 이후 매번 별도 명령창에서 프로그램을 실행할 필요가 없도록 서비스로 운영합니다.

## 실행 구성

| 구성 | 역할 |
|---|---|
| `run_managed.py` / main | 장치 연결 확인, 중복 실행 방지, 정지 유지로 제어 시작 |
| navigation | 휴대폰 위치 수신과 연결 인증 유지 |
| `access_portal.py` / portal | HTTPS 로그인, 시작 화면, localhost 대시보드 연결 |
| `--connection-check` | 제어기 없이 위치·날씨·웹 경로를 확인하는 선택적 읽기 전용 점검 기능 |

운영 서비스 정의는 `../prepare_services.py`에서 생성합니다. `../stage_on_pi.py`는 기존 원본 해시와 TLS를 확인하고 별도 폴더에 빌드하는 준비 도구입니다. 기존 위치 runner(`/usr/local/lib/safeguard-navigation`)와 인증서를 선행 조건으로 하므로 새 Pi에서는 이 환경부터 설정해야 합니다. `baseline_main_sha256.json`은 준비 도구의 대상 원본 확인용입니다.

[접속 서비스 설치 도구](../maintenance/SafeGuard_Access_20261031/README.md)는 고정 경로를 사용하므로 대상 환경과 기존 서비스를 확인한 뒤 적용합니다. 소스 복제·서비스 설치·ESP32 펌웨어 업로드는 각각 별도 작업입니다. 과거 maintenance 설치 도구를 순서대로 모두 실행하지 않습니다.

## 상태 확인과 종료

- 감시 재개 버튼의 활성화와 센서·열 모델 준비 상태를 함께 확인합니다.
- 화면 재접속과 제어 메인 재시작을 분리합니다. 메인·ESP32 재시작 후에는 정지 유지 상태를 확인하고 명시적으로 감시를 재개합니다.
- 위치는 15초, 날씨 표본은 최대 1800초 유효성을 적용합니다. 입력이 만료되면 최신 값으로 사용하지 않으며 예측 이력을 다시 수집할 수 있습니다.
- 종료는 대시보드 전체 정지 → 제어기 정지 보고 및 실제 출력 확인 → 정상 종료 순서로 진행합니다. USB 분리를 전체 정지 대신 사용하지 않습니다.
- 운영 전 인증서 유효기간과 이름, 연결 기기의 신뢰 설정을 확인합니다. 인증 정보·개인키·현재 위치·원시 실행 로그는 공개 저장소에 올리지 않습니다.
