## 제어·열 예측 소프트웨어 시험

| 시험 | 결과 | 확인 내용 |
|---|---|---|
| Pi Linux 전체 빌드·CTest | 5개 통과 | core, 입력/재개, 선제 보호, 관측기 회귀, 실내·외기 관측기 |
| Python | 44개 통과 | 접속 12, 위치 수신 10, 센서 허브 22 |
| main/hub/dashboard 통합 | 통과 | 가상 입력·출력 비활성 환경의 프로세스 연결 |
| Windows C++ | 4개 통과 | core, 관측기, 실내·외기 관측기, 선제 보호 |
| Node 대시보드 | 2개 통과 | 예측 표시, 결측/워밍업, 제어 비활성 표시, mmWave 존재/부재/입력 불가 구분 |

합성 입력과 해석해를 이용해 외기 변화에 따른 예측 변화, 600초 이력, 유효 ETA 60초 경계, 실측 35°C 직접 보호, 만료 입력 거부와 수동 정지 정책을 시험합니다. 해당 결과는 차량별 온도 예측 오차 측정과 구분합니다.

## 검증 범위와 재현

Linux 시험은 Pi 빌드에, Windows·Node 재검증은 GitHub 병합본에 대해 수행했습니다. 센서·출력 장치를 연결한 전체 경로 및 차량별 열 예측 정확도는 장치 구성과 환경을 맞춰 평가합니다. GitHub용 문서·UI 병합 이후 소스 전체의 Pi 재배포 시험을 이 결과에 포함하지 않습니다.
