# 실내·외기온도를 사용하는 열 예측

활성 모델은 `ambient_heat_balance_observer_v2`이며 `SafeGuard_Main/src/thermal_observer.hpp`에 구현합니다. 실제 실내온도와 휴대폰 위치로 조회한 Open-Meteo `temperature_2m`을 사용합니다. 외기온은 기상 모델 값이며 차량 외부 센서 실측값이 아닙니다. 촬영용 고정 온도와 실제 입력을 구분합니다.

## 계산과 제어 연결

`dT/dt = (Ta − T)/τ + q`

- T: 실내온도, Ta: 위치 기반 외기온도. 시간 단위는 초이며 q는 온도 변화율 단위의 순열유입 Q/C입니다.
- τ: 기존 문헌 그림에 적합한 약 19.02분. 차량별로 측정·보정한 R/C가 아닙니다.
- 약 5초 간격의 최근 600초 실내·외기 쌍에서, 구간 평균 외기온을 일정하다고 두는 지수 전이식으로 q를 최소제곱 적합합니다.
- 최신 외기온과 q가 유지된다는 가정으로 향후 300초 곡선과 35°C 도달 예상 시간을 계산합니다.
- 보호자 이탈·탑승자 확인·감시 중 등 기존 조건을 거쳐 **유효 ETA≤60초**이면 선제 보호를 요청합니다. 실제 실내온도 35°C 직접 보호와 수동 정지·보호 유지 정책도 보존합니다.

실내·외기 입력 출처/신선도, 시간 역행, 적합 오차, 급격한 변화, 팬/제어기 피드백을 검사합니다. 외기가 만료되면 촬영 상수나 만료 값을 대신 사용하지 않습니다. 600초가 지났다는 사실만으로 예측이 유효해지지는 않습니다.

## 검증과 한계

수학적 해석해 비교, 외기 변화에 따른 ETA 변화, 결측/가상 출처 거부, 기존 선제 보호·직접 보호 회귀를 시험했습니다. 실제 차량의 예측 오차는 미검증입니다. 차량 일사·환기 변화의 영향은 차량별 온도 기록과 비교해 평가해야 합니다.

실내 이력이 같고 전체 외기 이력에 일정한 편차가 생기면 q가 이를 흡수할 수 있습니다. 별도 일사/열유입 계측이 없는 모델의 식별 한계이며 R, C, 일사 유입을 각각 추정했다고 주장하지 않습니다.

`thermal.enabled=false / calibrated=false`는 호환용 RC 경로 설정입니다. 활성 관측기는 `literature_observer_enabled / predictive_control_enabled` 진입점을 사용합니다. 시간상수와 비교 모델의 출처는 [방법·참고 문헌](../maintenance/SafeGuard_Thermal_20261028/METHOD.md)에 있습니다.
