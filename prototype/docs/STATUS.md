# 구현 기능과 검증 결과

SafeGuard는 보호자 이탈 감지, 잔류 탑승자 증거 확인, 열 예측, 선제 보호 출력을 하나의 상태기계로 연결합니다.

| 구현 기능 | 확인 자료 |
|---|---|
| UWB 보호자 거리·이탈 판단 | 거리 원본 로그와 잡음·갱신주기 분석 |
| PIR·카메라 1차 탐지 | 센서 입력·카메라 움직임 실측 및 상태기계 시험 |
| mmWave 추가 재실 확인 | People Tracking 단독시험, 수신 원본·재실 판정 그래프 |
| 열 예측·선제 보호 | 관측기 수치 시험, ETA 경계·입력 유효성·직접 보호 회귀 시험 |
| 팬·부저·서보 요청과 수동 정지 | 출력 요청/응답 시험, 시연영상과 실제 대시보드 화면 |
| 웹·위치·날씨 연동 | HTTPS 접속, 휴대폰 실제 위치·기상값 수신, 서비스 재부팅·재시작 복구 |
