# 요구사항과 구현 경계

기준 자료는 최신 컨설팅 피드백 이미지, 보완 설계 및 구현 실행 보고서 21쪽, 중간발표 자료 14쪽입니다. 최신 피드백의 변경 방향을 먼저 반영하고 보고서의 상세 조건을 유지합니다. 표의 ‘구현 대상/대응’은 설계와 프로그램의 대응 관계이며, 실물 검증 완료를 뜻하지 않습니다.

## 기존 자료와 현재 진척의 차이

- 발표 9–11쪽은 실제 선행 프로토타입 사진·DHT22/릴레이 로그와 시뮬레이터 결과를 포함합니다. 선행 작업의 근거로 보존하되 현재 ESP32/SHT31/MOSFET 및 UWB/mmWave 결합의 실행 증거로 바꾸지 않습니다.
- 발표 12쪽의 ‘B OS 이미징 중 / C 착수 예정’은 현재 대화에서 확인한 진척보다 오래됐습니다. 현재 B는 OS/SSH와 카메라 촬영, C는 실제 Pi 거리 출력·평균·통신 단절/복구가 확인됐습니다.
- 현재 A firmware와 실제 배선, B의 TI 펌웨어·cfg·원시 로그는 이 패키지의 실제 장치 계약 검증에 필요합니다. 미제공 부분은 자동 정상값으로 대체하지 않습니다.
- 최신 피드백은 호흡을 핵심 완료 조건에서 분리하고, presence/미세 움직임을 본선 필수 수준으로 제시했습니다. 전력 로거 구매도 기본 완료 조건이 아닙니다.

## 검증 표현

소프트웨어 테스트 통과는 파싱·시간 조건·상태전이·출력 계약에 대한 증거입니다. 이를 센서 검출률, 실제 팬 작동률, 전력 절감률로 확대하지 않습니다. 실제 시연 성공은 실제 감지 경로와 실제 Fan/Buzzer 동작까지 연결한 회차에서만 집계합니다. REPLAY와 합성 입력 회차는 별도 분류합니다.
