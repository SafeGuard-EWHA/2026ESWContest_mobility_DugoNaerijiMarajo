SafeGuard Navigation Update 0.1.0 검증 기록

개발 환경 검증:
- 신규 Python 검사 35개 통과: 위치 입력/만료, 조회 좌표, API 캐시, 이동/재조회,
  시계 역행, HTTPS 인증서, 연결 코드/권한/입력 검증, 설치 보존/거부.
- 업데이트한 sensor_hub의 기존 검사 22개 통과.
- 기존 Ambient Update 검사 25개 통과.
- 실제 로컬 TLS 핸드셰이크와 HTTPS 요청: 신뢰 CA 및 서버 IP 검증을 켠 상태에서
  페이지 열기/연결/위치 수신/상태/정지 통과. 합성 좌표와 루프백 통신 사용.
- 브라우저 API 모의 검사: 연결/위치 자동 갱신/화면 이탈 시 중단 통과.
- 대시보드 DOM 모의 검사: 조회 좌표와 현재 좌표 구분, 만료 상태, 기존 표시 통과.
- 실제 메인 raw_input.jsonl의 payload 래핑 형태에 맞춘 로그 검사기 확인.
- 기존 C++ InputStore 계약 검사: 유효 외기/3초 전송 만료/무효 입력 통과.

실제 아이폰 17, 실제 Pi, 해당 핫스팟을 통한 최초 연결은 미검증.
사용자가 설치 후 위치 권한/인증서 신뢰/기기 간 접속을 확인해야 함.
새 코드의 자동 검사는 합성 입력을 사용했으며 실물 센서 측정으로 주장하지 않음.
기존 C++ 바이너리는 수정하지 않음. 환경에 CMake가 없어 이번 단계에서
C++ 전체 재빌드는 수행하지 않았음.
인증서와 비밀 키는 패키지에 없으며 사용자 Pi에서 생성함.
