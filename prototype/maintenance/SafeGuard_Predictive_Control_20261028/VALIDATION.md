# 검증 결과 — 2026-10-28

개발 환경 Linux, 실제 하드웨어 미연결. 통합 실험 완료는 사용자가 이번 진행에서 둔 가정이며 새로운 실제 시험 결과로 기록하지 않습니다.

- 현재 소스 CMake Release 빌드 및 CTest 4개 통과: core, 입력 계약/재무장, observer, predictive_control.
- 기존·연구용·선제 보호 표기 대시보드 Node 테스트 통과.
- 실제 observer의 600초 상승 이력: 현재 34.5°C, 약 51초 후 35°C 도달 → 실제 Core의 PROTECTION 및 팬·부저 요청 확인.
- 60초 경계 작동, 61초 미작동, 예측 OFF, 근거리 보호자, 누락·오래된·온도 불일치·NaN·음수 ETA 미작동 확인.
- 예측 입력 없이 실측 35°C 보호, 예측 상실 이후 보호 래치 유지, 비상정지 출력 차단 확인.
- 실제 main.cpp의 ActuatorLink로 팬·부저 ON, 서보 80° 명령 구성 확인. ManualControl에서 전체 정지·재개 동시 요청 시 정지 우선 확인. 실제 UART 송신·축 회전은 이 개발 테스트 범위 밖입니다.
- 설치기를 임시 프로젝트에 실행: 빌드·CTest·설치 성공, 위험35/서보80 보존, 롤백 원본 바이트 일치, 미지원 소스 변경 시 덮어쓰기 거부 확인.
- 기존 test_input의 stop_nonce 초기화 경고는 남아 있습니다.

파일의 테스트 결과는 실제 Pi 설치 및 차량 예측 정확도 검증 완료를 뜻하지 않습니다. 예측의 10분 준비 시간과 원 모델의 적용 한계는 README에 명시했습니다.
