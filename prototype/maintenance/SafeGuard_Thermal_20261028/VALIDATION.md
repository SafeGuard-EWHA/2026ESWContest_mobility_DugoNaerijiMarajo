## 문헌 그래프를 이용한 사전 모델 비교

출처: McLaren 2005 Fig.3. 7개 곡선의 0~60분, 5분 간격 시각 약독 자료.
**원시 계측 데이터가 아니며, 동일 연구·동일 차량 범위의 평가입니다.**
평가할 곡선을 제외한 나머지 곡선에서 시간상수를 적합하고, 평가 곡선의 직전 10분 3개 점으로
기울기를 구해 미래를 예측했습니다. 아래 수치는 `research/analyze.py`를 재실행해 확인했습니다.

| 5분 후 온도 예측 / 70개 비교점 | MAE (°C) | 최대 절대오차 (°C) |
|---|---:|---:|
| 현재 온도 유지 | 1.254 | 3.889 |
| 직선 추세 외삽 | 0.730 | 4.167 |
| 시간상수 + 관측 추세 | 0.563 | 3.440 |

10분 후 동일 계열 모델 MAE 0.890°C, 최대 절대오차 6.754°C로 장기 예측 오차가 커졌습니다.
따라서 구현의 표시 예측 범위는 5분으로 제한했습니다. 평균 오차만을 이용해 안전성을 주장하지 않습니다.

초기 고정 곡선 모델의 곡선 분리 평가 MAE는 1.888°C, 최대 절대오차 5.971°C였으며,
35°C 도달 시점을 약 5.51분 늦게 계산한 사례가 있었습니다. 초기 곡선을 자동 제어에 연결하지 않은 이유입니다.
7개 중 6개는 10분 이력 확보 시점에 이미 35°C 이상이므로, 이 모델은 단독으로 초기 보호를 완성하지 못합니다.

**실시간 구현과 문헌 평가의 차이:** 실시간 구현은 약 5초 간격의 최근 10분 데이터로 회귀합니다.
문헌은 5분 간격의 3점 회귀입니다. 또한 실제 구현의 최종 시간상수는 전체 7개 곡선 적합값입니다.
따라서 위 MAE를 설치된 실시간 시스템의 정확도나 독립 검증 성능으로 표시하면 안 됩니다.
최종 시간상수에 대한 미사용 외부 데이터 검증은 없습니다.

그림 읽기 오차 ±1°F를 독립적으로 교란한 민감도 계산은 `research/results.json`에 기록했습니다.
이 민감도 범위는 통계적 신뢰구간이나 실제 차량 예측 구간이 아닙니다.

## 재현

Pi 설치기는 CMake/CTest로 3개 C++ 테스트를 실행한 뒤에만 설치합니다.
개발용 전체 재현:

```bash
python3 tests/test_install.py /path/to/original/SafeGuard_Main
python3 research/analyze.py
```

두 번째 명령에 NumPy와 SciPy가 필요합니다. 실제 Pi 메인에는 이 패키지들이 필요하지 않습니다.
실행 시나리오 기록은 `tests/scenario_results.json`, 설치기 원본 출력은 `tests/install_test.log`에 있습니다.
기록 속 임시 경로는 개발 환경의 경로이며 Pi에 존재할 것으로 가정하지 않습니다.
