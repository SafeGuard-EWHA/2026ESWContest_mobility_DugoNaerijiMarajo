## 모델 선택

기본 열 수지: `C dT/dt = (Ta-T)/R + Q`.
입력과 조건이 일정하면 `T(t+h)=Teq+(T(t)-Teq) exp(-h/tau)`이며 `tau=RC`, `Teq=Ta+RQ`입니다.
차내 온도 곡선만으로 R,C,Q를 각각 고유하게 알아낼 수 없으므로 임의 물리 계수를 차량 식별 결과처럼 부여하지 않았습니다.
Fig.3 약독 데이터의 온도 상승에 `A(1-exp(-t/tau))`를 공동 적합한 결과:

- A = 23.0268767056°C
- tau = 19.0228211695분

이는 **본 작업에서 추정한 계수**이며 논문 저자가 보고한 RC 계수가 아닙니다.
`research/analyze.py`에 수치, 적합, 곡선 분리 평가, 그림 읽기 민감도 계산을 모두 남겼습니다.
재계산에만 NumPy/SciPy가 필요하며 Pi 실시간 모듈에는 필요하지 않습니다.

실시간 계산은 최근 10분 차내 온도에 최소제곱 직선을 적합해 기울기 s를 구하고,
`T_hat(h)=T_now+s*tau*(1-exp(-h/tau))`를 계산합니다. 외기는 이 적응형 공식에 직접 들어가지 않습니다.
현재 기울기를 시작점으로 두는 단기 추정이며 일정 외기·유효 열원이라는 국소 근사를 사용합니다.
기울기가 음수이면 냉각 추세를 표시할 수 있으나, 팬이 켜진 구간은 모델 대상에서 제외합니다.
예측 범위는 300초, 표시 간격은 10초입니다. 도달 시간은 지수식의 해를 계산하므로 그래프 간격에 의존하지 않습니다.
온도가 이미 기준 이상이면 모델 예측과 별개로 실측 기준 도달을 표시합니다.

## 초기 구간

이력 600초 미만은 실측 추세 예측을 내지 않습니다. 대신 조건을 명시한 일사 노출 주차 참고 시나리오만 허용합니다.
`Teq=현재 외기+A`라는 추가 가정이 필요합니다. 외기와 일사가 검증되지 않았으므로 이 시나리오를 현재 차량의
도달 예측이나 보호 명령으로 쓰지 않습니다. API 외기는 현장 외기 센서 측정이 아닙니다.
외기 22.2–35.6°C 밖이면 시나리오를 숨깁니다. 범위 안이라는 이유만으로 연구 조건이 일치하는 것도 아닙니다.

## 구현상의 품질 조건

- 매 수신 온도의 신선도를 검사하며 약 5초 간격으로 이력을 저장합니다. 이력 길이는 약 10분으로 제한합니다.
- 기존 온도 만료시간(현재 2초) 이상 입력 단절, 출처 변경, 타임스탬프 역행은 이력을 초기화합니다.
- 온도 입력/예측 -40~100°C 범위, |기울기| 3°C/분 이하, 직선 잔차 RMSE 2°C 이하를 사용합니다.
  이 값들은 구현상의 거부 기준이며 센서 사양, 통계적 신뢰구간, 검증된 안전 한계가 아닙니다.
- 입력 누락을 0°C로 대체하지 않습니다. 미래 값·NaN·REAL 모드의 DEMO/REPLAY 출처를 거부합니다.
- 팬 요청/팬 보고가 켜졌거나 REAL 제어기 보고가 불명확하면 이력을 지우고 계산을 보류합니다.
- 모델 상태와 오차 관련 필드를 JSON 로그에 남기며, 예측으로 기존 출력 요청을 수정하는 경로는 없습니다.

## 왜 아직 자동 보호를 연결하지 않았는가

동일 논문의 다른 곡선으로 시험한 것과 다른 차량에서 검증한 것은 다릅니다.
그래프 약독 연구에서 7개 중 6개 곡선은 10분 이력 확보 시점에 이미 35°C 이상이었습니다.
따라서 이력 기반 모델만으로 초기 선제 경고를 보장할 수 없습니다.
실제 차종, 일사 변화, 문·창 개방, 센서 위치, 겨울 환경, 팬 냉각을 반영한 추가 검증이 필요합니다.
35°C는 사용자 프로젝트의 제어 기준이며 인체 안전을 보장하는 의학적 경계값으로 해석하지 않습니다.
