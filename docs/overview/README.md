# SafeGuard 동작 설명 그림

- `system-flow.svg`: UWB 이탈부터 PIR/카메라, mmWave, 열 예측, 보호 출력까지의 구현 흐름.
- `predictive-protection.svg`: 실내·외기 입력, 600초 이력, 300초 예측과 60초 선제 보호 기준.

두 그림은 구현 구조와 판단 기준을 설명하는 벡터 이미지입니다. 실제 측정 그래프와 시연 사진은 기존 원본을 그대로 사용합니다. 데이터·시험 결과를 새로 만들어 넣지 않았습니다.
