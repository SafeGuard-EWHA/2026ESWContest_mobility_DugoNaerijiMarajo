# hardware/camera — 블록 B (Pi 5 + Camera Module 3 움직임 검출)

상태: Pi 5 실측 1회 (2026-10-24, 2분), 그 녹화로 판단 규칙 조정

## `camera_motion.py`

picamera2 공식 예제(capture_motion)와 같은 방식이다. 320×240 저해상도 밝기(Y) 채널을 이전 프레임과 비교한다. OpenCV 없이 numpy만 쓴다.

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| `--pixel-thresh` | 25 | 밝기 차이가 이보다 큰 픽셀을 "바뀐 픽셀"로 셈 (0~255) |
| `--ratio-thresh` | 0.01 | 바뀐 픽셀이 화면의 1%를 넘으면 그 프레임은 움직임 |
| `--light-thresh` | 0.6 | 60%를 넘으면 조명 변화나 흔들림으로 보고 무시 |
| `--hold` | 2.0 | 마지막 움직임 뒤 2초 동안 움직임 상태 유지 (깜빡임 방지) |
| `--min-frames` | 3 | 3프레임(0.3초) 연속으로 바뀌어야 움직임으로 인정 |
| `--light-settle` | 1.0 | 조명 변화 뒤 1초 동안 판단 쉼 (자동 노출 안정) |
| `--replay CSV` | 없음 | 녹화한 CSV를 다시 넣어 판단만 돌림. 카메라 없이 노트북에서 규칙을 바꿔 볼 수 있음 |
| `--roi X0 Y0 X1 Y1` | 전체 | 볼 영역 (0~1 비율). 창밖 사람을 빼려면 뒷좌석만 지정 |
| `--csv`, `--snap-dir` | 없음 | 프레임별 기록, 움직임 시작 순간 사진 저장 |

```bash
python3 hardware/camera/camera_motion.py --duration 120 --csv ~/cam.csv --snap-dir ~/cam_snaps
```

출력 예: `[  12.0s] 10.0 프레임/초 | 움직임 | 최대 변화   3.9% | 움직임 프레임 6`

가짜 영상 시험 결과: 센서 잡음 0%, 손 크기 물체 3.9% → 움직임, 불 켜기 100% → 조명 변화로 무시, `--roi`로 창문 영역 변화 제외 확인.

## Pi 실측 (2026-10-24, 과방, 2분, 10 프레임/초)

0~29초 빈 화면 → 29~43초 손 흔들기 → 75~95초쯤 조명 하나를 껐다 켜기 → 100~120초 손 흔들기.

| 구간 | 처음 규칙 (1프레임, 쉬기 없음) | 지금 규칙 (3프레임 연속, 조명 뒤 1초) |
|---|---|---|
| 빈 화면 (최대 변화 0.8%) | 오경보 없음 | 오경보 없음 |
| 손 흔들기 2번 | 29.3초, 100.2초에 검출 | 29.6초, 100.5초에 검출 (0.3초 늦음), 흔드는 동안 끊김 없음 |
| 조명 껐다 켜기 | 63~74% 프레임 4개는 조명으로 무시됐지만 **가짜 움직임 3번** (74.9, 81.1, 85.6초) | **가짜 0번** |

- 조명을 바꾸면 63% 큰 변화보다 **1~3초 앞**에 20~30% 작은 변화가 1~2프레임 먼저 나왔다 (자동 노출). 그래서 "조명 뒤 쉬기"만으로는 못 막고, 연속 프레임 조건이 필요했다.
- 2프레임 연속 규칙으로는 85.6~85.8초의 2프레임짜리 가짜가 남았다 → 3프레임으로 정함.
- 이 기준은 **녹화 1회(2분)**로만 정한 값이다. 실차·전동차에서 다시 확인할 것.
### 시험 2 (같은 날, 지금 규칙, 2분)

| 구간 | 결과 |
|---|---|
| 0~20초 빈 화면 | 정지 (변화 0.0%) |
| 20~40초 손 흔들기 → 앉기 | 22.7초에 움직임 시작, 앉는 동안 유지 |
| **41~81초 가만히 앉기** | **정지** (변화 최대 0.3%, 기준 1%보다 작음) → **카메라는 정지한 사람을 못 잡는다** |
| 81.7~85초 일어나 나가기 | 움직임 |
| 85~100초 조명 하나 껐다 켜기 | 정지. 단 **화면 변화가 0.0%**라 이 조명은 카메라 장면에 영향이 없었다 → 조명 필터 검증은 시험 1 재생 결과로만 확인된 상태 |

- 같은 날 레이더 시험 B(차량용 cfg, 1명 정지)에서는 정지 구간 95.7%를 1명으로 추적했다.
  **카메라 = 움직임 1차 확인, 레이더 = 정지한 사람까지 재실 확인**이라는 역할 분담의 실측 근거.
- 조명 필터를 다시 확인하려면 카메라 장면을 직접 비추는 조명(천장 메인 등)으로 시험할 것.
  → 과방에서는 생략하고, **전동차·실차 시험 때 실내등 켜고 끄기**로 확인한다 (차 안의 실제 조명 변화).

## 주의

- **카메라는 흔들리지 않게 고정**해야 한다. 흔들리면 화면 전체가 바뀌어 움직임이나 조명 변화로 잡힌다.
- 켜고 처음 2초는 자동 노출이 자리 잡는 시간이라 판단하지 않는다.
- `rpicam-hello` 같은 다른 카메라 프로그램이 켜져 있으면 열 수 없다.
- 이 방식은 **움직임**만 본다. 가만히 있는 사람은 잡지 못하므로 레이더(mmWave)와 함께 쓴다.
